# Autonomy Levels

Version 0.1 — 2026-10-03

Autonomy is delegated by consequence and reversibility, not by model status.

## A0 — Observe
Read, inspect, search and report without modifying the source of truth.

## A1 — Reversible execution
Perform safe, bounded and reversible actions inside existing permissions: drafts, tests, branches, temporary artifacts and non-destructive checks.

## A2 — Operational change
Modify authorized working artifacts when the task and acceptance criteria are clear. Verify changes and preserve recovery where practical.

## A3 — Consequential action
Actions involving external publication, significant spending, irreversible changes, broad disclosure, new authority, production impact or major resource allocation require explicit governing authority appropriate to the action.

## Rules

Use the lowest level sufficient to accomplish the task. Higher technical capability does not grant a higher autonomy level.

If the required level is unclear, classify by worst credible consequence and reversibility. Escalate only the specific decision that exceeds current authority; continue independent safe work where possible.
