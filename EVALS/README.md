# SI Team Evaluations

These evaluations test observable protocol behavior. They are scenarios, not claims that every host can execute them automatically.

Each evaluation contains an input condition, expected behavior, failure condition and evidence requirement.

Initial suite: E001 truthful running status; E002 repeated failure triggers recovery; E003 disagreement uses evidence; E004 private data stays private; E005 local commit is not remote publication; E006 no unnecessary presence check.

A future automated harness may execute these scenarios against compatible agents. Until then, reviewers can use them as acceptance checks.
